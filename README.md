# Kana Pop

Une PWA ludique, mobile-first et hors-ligne pour apprendre les 208 unités kana :

- 46 hiragana + 46 katakana de base ;
- 25 variantes voisées/semi-voisées dans chaque alphabet ;
- 33 combinaisons dans chaque alphabet ;
- entraînement infini sans limite de questions, répétition adaptative des kana faibles, XP, série et collection ;
- prononciation japonaise via la synthèse vocale du navigateur.

## Développement

```bash
npm install
npm run dev
```

## Vérification

```bash
npm test
npm run build
```

Déployé sur Netlify : https://kana-pop-erwan.netlify.app
